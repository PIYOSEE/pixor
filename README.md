# Pixor

Pixor is a full-stack MERN Text-to-Image Generator web application that allows users to generate AI images from text prompts using the ClipDrop API.

...

## 🚀 Features
- Text-to-image generation using AI
- User authentication (JWT-based)
- Secure backend APIs
- MongoDB Atlas database integration
- Image generation API handling
- Tested APIs using Postman
- Responsive and user-friendly UI

...

## 🛠 Tech Stack
Frontend :-
- React
- Tailwind CSS

Backend :-
- Node.js
- Express.js

Database :-
- MongoDB Atlas

APIs & Tools :-
- ClipDrop API (Text-to-Image)
- Postman (API testing)
- JWT Authentication
